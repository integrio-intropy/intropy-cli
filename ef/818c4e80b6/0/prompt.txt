## 4. dependencies.go (PR #5)

Templates can declare `spec.dependencies` (`DependencySpec{Template, Output, Values}` — Output/Values are Go-template expressions over the parent's resolved values). During `int create`, each dependency is rendered **as a sibling directory** of the component (single path segment enforced), recursively up to depth 5, deduped by a visited set, skipped if the target already carries a scaffold record from the same template (with value-drift warnings), refused for foreign/unmanaged non-empty dirs, and `--force` never propagates. Each rendered dependency gets its own scaffold.json; the parent records them in `dependsOn`. Effect on discovery: this is how a component auto-creates the shared Contracts project — so `sys create`'s workspace scan finds the `shared-library` scaffold as a sibling. It does not change the scan itself.
