## Rex in brief
- A key is modifiers and one key joined with `+`: `ctrl+a`, `shift+cmd+d`. Rex spells
  modifiers in the order ctrl, alt, shift, cmd; `super` and `command` mean cmd, `opt` and
  `option` mean alt and `control` means ctrl.
- Named keys: enter, esc, tab, space, backspace, delete, insert, home, end, pageup,
  pagedown, left, right, up, down, f1 to f25. Any other key is its own character: `-`,
  `=`, `,`, `[`, `` ` ``.
- Keys are unshifted, as a US key cap reads, and a capital letter is `shift+` the letter:
  `!` is `shift+1`, `"` is `shift+'`, `#` is `shift+3`, `$` is `shift+4`, `%` is
  `shift+5`, `&` is `shift+7`, `(` is `shift+9`, `)` is `shift+0`, `*` is `shift+8`, `+`
  is `shift+=`, `:` is `shift+;`, `<` is `shift+,`, `>` is `shift+.`, `?` is `shift+/`,
  `@` is `shift+2`, `^` is `shift+6`, `_` is `shift+-`, `{` is `shift+[`, `|` is
  `shift+\`, `}` is `shift+]`, `~` is `shift+``.
- A mode is a named set of bindings that apply only while it is active. `rex.bind("resize/left",
  "pane.resize", { direction = "left" })` binds left inside mode resize, which exists once a
  key is bound in it. Enter it with `client.mode.enter` and `{ name = "resize" }` (`once = true`
  leaves after one key), leave it with `client.mode.exit` or escape. `rex.mode("resize",
  { exclusive = true })` makes every other key do nothing while the mode is active. A mode
  binding must name an action, never a function. Keys that work all the time are bound
  with no mode at all, as `rex.bind("ctrl+p", ...)`: a program's normal or default mode is
  that, never a Rex mode named normal.
- `rex.bind(key, action[, args])`: `rex.bind("cmd+d", "pane.split", { direction = "right" })`.
  `rex.unbind(key[, action])` removes a key's bindings, Rex's own default included:
  `rex.unbind("cmd+k")`. A later rex.bind of the same key replaces an earlier one.
- For anything no action does: `rex.action{ name = "x", title = "X", args = { what = "string?" },
  run = function(ctx, args) ... end }`, then bind "x". Inside run, `rex.exec{ "cmd", "arg" }`
  runs a command and `rex.client.queue("pane.zoom", {})` performs an app action.

The actions a key can be bound to, with their arguments (`?` marks an optional one). Only an
action marked "also" has dotted names such as `pane.split.right`, which is `pane.split` with
`{ direction = "right" }`; every other action is bound by its name with arguments.

## zellij
- zellij's normal mode is Rex with no mode active: bind its keys plainly, as `ctrl+p`,
  never as `normal/ctrl+p`, and never make a mode named normal. The other modes (locked,
  pane, tab, resize, move, scroll, search, session) are Rex key modes. Bind the keys
  that enter a mode with `client.mode.enter` and a `name`, and the keys inside it as
  `mode/key`. zellij leaves most modes after one action only
  when the binding says `SwitchToMode "Normal"`; a mode the user stays in becomes an
  exclusive Rex mode (`rex.mode(name, { exclusive = true })`), and one that acts once
  becomes `client.mode.enter` with `once = true`.
- A binding that runs an action and then says `SwitchToMode "Normal"` leaves the mode
  after the action. A Rex binding runs one action, so define one custom action for all
  such bindings and pass the real action and its arguments to it. Use exactly this,
  and never one wrapper per action:
  ```lua
  rex.action{
    name  = "then_normal",
    title = "Run an action and return to normal mode",
    args  = { action = "string", args = "object?" },
    run   = function(ctx, args)
      rex.client.queue(args.action, args.args or {})
      rex.client.queue("client.mode.exit_all")
    end,
  }
  rex.bind("pane/d", "then_normal", { action = "pane.split", args = { direction = "down" } })
  ```
- `shared_except` and `shared_among` blocks apply to several modes: bind the same keys
  in each Rex mode they apply to.
- `clear-defaults=true` means only the file's bindings exist; without it, zellij's
  default bindings are also in effect, and the agent should migrate the defaults the
  user kept only if asked. Say in the report which case this is.
- `Ctrl g` is `ctrl+g`; `Alt n` is `alt+n`; `Ctrl Shift x` is `ctrl+shift+x`.
- zellij actions map as follows. NewTab: client.tab.new; CloseTab: client.tab.close;
