   ## The rule

   The topology declares a Port (a name); the environment resolves it to an adapter
   implemented as a Dapr binding. Ports-and-adapters: "port" is the topology-level
   concept, "adapter"/"binding" is the Dapr-level implementation.

   ## Mapping

   - ConnectorRef → PortRef
   - Connectors.cs / public static class Connectors → Ports.cs / Ports (scaffolded
     SystemHost files)
   - Connector as a resource/kind name in models, topology JSON, and CLI output → Port:
