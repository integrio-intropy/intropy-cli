## 3. What `feature/flow-slot-create` adds

`git diff --stat main...HEAD`: 45 files, +6439/−342. Commits (all `Entire-Checkpoint` trailers): "New flow gui", "Sync host", "Start stop system", "Test seeding", "Fix dash", "Derived facts", "Derive outputdir".

It turns the dashboard's flow view from read-only into a **build-and-run surface**, plus a suggestion engine shared with the CLI:
- **Create from the flow view**: new `web/src/components/CreateDrawer.tsx`, `form.tsx`, `useTemplateFields.ts`; API `POST /api/templates/{name}/create` and `GET /api/templates/suggestions/{name}` (`internal/dashboard/templates.go`).
- **Sync/assemble the host from the UI**: `internal/dashboard/systems.go` + `POST /api/systems/{path...}` running `sys create` / `sys update` (with `force` for diverged declarations).
- **Start/stop the system locally**: `internal/dashboard/run.go` supervises `dotnet run` per host, with a log tail and process-group kill; `GET/POST/DELETE /api/run/{path...}`; children are parented to dashboard lifetime and shut down on drain.
- **Test-file seeding**: `internal/dashboard/testdata.go` + `SeedDrawer.tsx`, `GET /api/testdata/{path...}` and `POST /api/seed`, copying committed `testdata/&lt;port&gt;/` samples into the localstorage dev inbox `test/&lt;port&gt;` derived from `graph --development`; documented in the new README section "Seeding test files from the dashboard".
- **Prompt-time workspace facts / suggestions**: `internal/template/facts.go`, `suggest.go`, `internal/system/facts.go` — scaffold records across a workspace index topics/contracts/ports and feed both `int create` prompts and the dashboard drawer; plus `int create` now derives the output dir from the resolved kebab-cased `name` when neither `-n` nor `-o` is given (`cmd/intropy/int_create.go`, README lines ~206).
