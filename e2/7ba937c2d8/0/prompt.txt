## 1. Directory layout

```
intropy-cli/
├── cmd/intropy/          # ALL cobra command wiring + main.go (package main)
├── internal/             # business logic, imported by the cmd layer
```

There is **no `pkg/` directory**. All reusable logic lives under `internal/`. The convention is a **thin `cmd/intropy` cobra layer** that parses flags and delegates to an `internal/&lt;domain&gt;` package exposing an `Options` struct + top-level function (e.g. `template.Create`, `deploy.Create`, `template.Describe`).

Note: **`int migrate` does not exist** anywhere in the codebase (grep found nothing). The existing `int` subcommands are: `create`, `list`, `describe` (plus post-create skills install logic). So `int run` will be a genuinely new subcommand.
