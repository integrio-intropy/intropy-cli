## 5. Layout &amp; conventions

- **Packages** (`CONTRIBUTING.md:216-224`): `cmd/intropy/` = Cobra commands, one file per command + adjacent `_test.go`; `internal/template/` = fetch/validate/describe/render + scaffold record; `internal/deploy/` = manifests generation (thin consumer of `internal/template`); `internal/skill/` + `internal/skill/oci/`. A new noun would follow `internal/deploy`'s shape: `internal/system/` (or similar) with `Create(ctx, CreateOptions) error`, `CreateOptions` carrying `Stdin/Stdout/Stderr/HTTP/UserAgent` + `Owner/Repo/GitHubBaseURL` test overrides, and a `CreateResult` with stable additive JSON. Package doc convention: see `internal/template/doc.go` and the package comment at `internal/deploy/create.go:1-6`.
- **Errors**: wrap with context (`fmt.Errorf("write scaffold record: %w", err)`); `usageError` via `newUsageErrorf` for exit code 2 (`cmd/intropy/errors.go`, mapped in `main.go:16-33`); sentinel errors like `ErrScaffoldNotFound` with `errors.Is` checks (`deploy/create.go:93`); `SilenceUsage`/`SilenceErrors` set once on root (`root.go:21-22`); `RunE` never calls `os.Exit`. Shared `--output` validation helper: `validateOutputFlag` (`root.go:42`).
- **Output**: program output → `cmd.OutOrStdout()`; progress/diagnostics/warnings → `cmd.ErrOrStderr()` (e.g. `fetching %s/%s@%s`, `created %s from …` at create.go:82/98; `warning: …` at int_list.go:43). No logging library; plain `fmt.Fprintf`. Tables via `text/tabwriter` (int_list.go:60). Machine output via `json.Encoder` with `SetIndent("", "  ")` or an `--output-json` file/`-` sentinel. Cancellation: `signal.NotifyContext(cmd.Context(), os.Interrupt, syscall.SIGTERM)` in each long-running `RunE`.
- **Testing patterns**:
  - Cmd-level: execute `rootCmd` in-process with `rootCmd.SetArgs([...])`, buffers wired via helper `resetRootIO` (`cmd/intropy/skills_list_test.go:83`) and `writeFileT` (:94); `t.Chdir(t.TempDir())`; scaffold fixture helper `writeScaffoldT` (`cmd/intropy/int_list_test.go:12`). Full examples: `int_list_test.go`, `root_test.go`.
  - Pure-logic cmd tests: `cmd/intropy/int_create_test.go` (subtests on `resolveCreateName`, asserts `errors.As(err, &amp;ue)` for usage errors).
  - Package-level: `httptest` GitHub stub — `newTemplateServer` (`internal/template/create_test.go:35`) and `newManifestsServer` (`internal/deploy/create_test.go:163`, which deliberately `t.Error`s if `releases/latest` is hit to prove version pinning), tarballs built by `buildTarGz`, injected through `HTTP: srv.Client()`, `Owner/Repo/GitHubBaseURL`. Scaffold fixture via `template.WriteScaffold` + round-trip through `LoadScaffold` so numbers arrive as `float64` (`deploy/create_test.go:181-205`) — a real trap for any code reading `values` numerics.
  - `make check` = fmt + vet + test; `make ci` adds tidy/lint/`-race`.
